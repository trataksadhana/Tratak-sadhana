# Sadhna Foundation — Next.js NGO Website

A modern, responsive, bilingual-ready NGO website for **Sadhna Foundation (साधना फाउंडेशन)**.

## Design direction

The information architecture takes inspiration from the public patterns visible on established NGO sites such as Akshaya Patra: strong mission-led hero, programme pillars, impact storytelling, campaigns/get-involved paths, updates, and a prominent donation journey. The implementation here is original and uses Sadhna Foundation's own branding, content structure, imagery and UI components.

## Stack

- Next.js App Router
- React 19
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Local optimized-ready image assets

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## GitHub deployment

1. Create a GitHub repository, e.g. `sadhna-foundation`.
2. Upload the contents of this folder.
3. Import the repo into Vercel or another Next.js host.
4. Set the production domain to `sadhnafoundation.org` when ready.

## Before launch — important

The template deliberately does **not** invent impact statistics or tax benefits. Replace the `—` metrics with verified programme records, and add the current 80G certificate/wording only after verification.

Also connect:

- `/donate` to the foundation's verified Razorpay/UPI/bank donation flow.
- `/volunteer` and `/contact` forms to email, Formspree, Supabase, CRM or your preferred backend.
- Social links in the footer to official accounts.
- Exact legal documents to `/legal`.
- Real event dates/locations before publishing.
